`@glass-midas/react/components`: every glass component as a React component (`GlassSurface`, `GlassButton`, `GlassCallout`, `GlassCode`, `GlassTabs`, `GlassTab`, `GlassNav`, `GlassSearch`, `GlassScrollbar`), for React 18 and 19 alike. Glass options and component attributes are camelCase props written as kebab-case attributes; non-string properties like `source` and `scroller` are assigned on the element; events are `onSelect` and `onNavigate`; `ref` is the element. `@glass-midas/components` is an optional peer dependency, needed only for this entry point.
