New package: glass components as Web Components, for any framework or none. `gm-surface`, `gm-callout`, `gm-code` (with a copy button), `gm-tabs` (synced and remembered across the page), `gm-nav` (a droplet under the current link, scroll spy, and a cancelable `gm-navigate` event for smooth-scroll libraries), `gm-search` (kube.io's search box with a pluggable `source`) and `gm-scrollbar` (a glass thumb). Glass options are attributes; styles are in `@glass-midas/components/styles.css`, themed through custom properties. Large still surfaces use the blur tier by default (`variant="full"` opts into refraction).
