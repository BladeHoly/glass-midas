New package: `glass-midas`, the docs from the terminal for people and coding agents. `list` the components (or every page, or a section), read any page as Markdown with `docs <name>` (a component, its element or a path), `find` pages by name, description and text, and `setup` a plain HTML, React or Astro project (offline, with the project's package manager). `list` and `find` take `--json`. Reads the published docs; `GLASS_MIDAS_DOCS` points it at another copy.
