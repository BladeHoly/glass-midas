`@glass-midas/cli` brings these docs to the terminal, for you or for a coding agent working in
your project. It reads the published site, so it's always current, and prints Markdown.

```sh
npx @glass-midas/cli list
```

Or install it, and call it `glass-midas`:

## Commands

| Command                                         | Prints                                                                      |
| ----------------------------------------------- | --------------------------------------------------------------------------- |
| `glass-midas list [components\|all\|<section>]` | The components, every page, or one section, with what each is for.          |
| `glass-midas docs <name>`                       | A page as Markdown. `<name>` is a component, its element or a path.         |
| `glass-midas find <words>`                      | Pages that mention every word: by name and description first, then by text. |
| `glass-midas setup [html\|react\|astro]`        | How to install and load glass-midas in this project. Works offline.         |
| `glass-midas template`                          | The [templates](/templates/overview/), by group.                            |
| `glass-midas template <name>`                   | Copies a template into `./<name>`, and says how to run it.                  |

`list` and `find` take `--json` for scripts and agents. `docs` accepts `search`, `gm-search`,
`Search` and `components/search` alike; an unknown name suggests close ones.

`setup` picks the package manager from the project's lockfile, and the kind of project from its
dependencies when you don't name one.

`template <name>` copies a template's page, script, React twin, the shared kit it uses and its
art. `--html` leaves out the React files, and `--react` leaves out the page and its script.
`--out <dir>` picks the folder. It won't overwrite a file that's already there unless you add
`--force`.

```sh
glass-midas docs gm-tabs        # the tabs page, attributes and all
glass-midas find frost          # every page that covers frost glass
glass-midas setup react         # install, load once, use
glass-midas template checkout --react --out src/checkout
```

## For agents

Point your agent at the CLI, or straight at the site:

- [`/llms.txt`](/llms.txt): what glass-midas is, and every page.
- [`/llms-full.txt`](/llms-full.txt): every page in one file.
- Any page plus `.md`, like [`/components/search.md`](/components/search.md).
- [`/docs.json`](/docs.json): the page index the CLI reads.

Set `GLASS_MIDAS_DOCS` to read another copy of the docs, such as a local build:
`GLASS_MIDAS_DOCS=http://localhost:4321/ glass-midas list`.
