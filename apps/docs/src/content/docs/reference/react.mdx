```ts
import { Glass, useGlass } from '@glass-midas/react';
```

Thin wrappers over [`createGlass`](/reference/core/#createglass): they create the surface after
mount, pass option changes to `update()`, and destroy it on unmount. Requires React 18 or newer.

## Glass

```tsx
<Glass glass={{ radius: 28, thickness: 32 }} className="panel">
  …
</Glass>
```

A `div` with glass attached and no other styling. It accepts every `div` prop, plus:

| Prop    | Type           | Description                                                 |
| ------- | -------------- | ----------------------------------------------------------- |
| `glass` | `GlassOptions` | Options for [`createGlass`](/reference/core/#glassoptions). |

## useGlass

```ts
function useGlass<T extends HTMLElement>(ref: RefObject<T | null>, options?: GlassOptions): void;
```

Attaches glass to any element you render:

```tsx
function Toolbar() {
  const ref = useRef<HTMLElement>(null);
  useGlass(ref, { radius: 999, bezel: 12 });
  return (
    <nav ref={ref} className="toolbar">
      …
    </nav>
  );
}
```

Changes to any option except `tier` update the live surface. A change to `tier`
replaces it.

## Components

```ts
import {
  GlassButton,
  GlassCallout,
  GlassCode,
  GlassNav,
  GlassScrollbar,
  GlassSearch,
  GlassSurface,
  GlassTab,
  GlassTabs,
} from '@glass-midas/react/components';
```

Every [glass component](/components/overview/) as a React component, from the
`@glass-midas/react/components` entry point (install `@glass-midas/components` too, and load its
stylesheet). Importing it registers the elements. They work the same in React 18 and 19:

- **Glass options are props in camelCase**, written to the element as its attributes:
  `specularSaturation={2}` becomes `specular-saturation="2"`, `caustics={false}` becomes
  `caustics="false"`. So are each component's own attributes (`labelCopied` → `label-copied`).
- **Properties** that aren't strings, like the search box's `source` or the scrollbar's
  `scroller`, are assigned on the element after every render.
- **Events** become `on` props: `GlassSearch`'s `onSelect` listens to `gm-select` and `GlassNav`'s
  `onNavigate` to `gm-navigate` (call `preventDefault()` on either to take over), and
  `GlassTabs`' `onChange` to `gm-change`, which only reports the new tab.
- **`ref`** gives you the element itself (`GmSearch`, `GmScrollbar`…), with its methods.

```tsx
import '@glass-midas/components/styles.css';
import { GlassNav, GlassSearch } from '@glass-midas/react/components';

export function Header({ pages }: { pages: { label: string; href: string }[] }) {
  const router = useRouter();
  return (
    <>
      <GlassSearch
        material="frost"
        hotkey="k"
        source={(q) => pages.filter((p) => p.label.toLowerCase().includes(q.toLowerCase()))}
        onSelect={(e) => {
          e.preventDefault();
          router.push(e.detail.href);
        }}
      />
      <GlassNav orientation="vertical">
        <a href="/docs" aria-current="page">
          Docs
        </a>
        <a href="/blog">Blog</a>
      </GlassNav>
    </>
  );
}
```

Each kind of component is also its own entry, which registers only its elements. Import from
there to ship less; `@glass-midas/react/components` has them all.

| Entry         | Component        | Element        | Its own props                                                   |
| ------------- | ---------------- | -------------- | --------------------------------------------------------------- |
| `/surfaces`   | `GlassSurface`   | `gm-surface`   |                                                                 |
|               | `GlassButton`    | `gm-button`    | `shape`                                                         |
|               | `GlassCallout`   | `gm-callout`   | `type`, `heading`                                               |
|               | `GlassCode`      | `gm-code`      | `labelCopy`, `labelCopied`                                      |
| `/navigation` | `GlassTabs`      | `gm-tabs`      | `sync`, `onChange`                                              |
|               | `GlassTab`       | `gm-tab`       | `label`                                                         |
|               | `GlassSegmented` | `gm-segmented` | `value`, `label`, `onChange`                                    |
|               | `GlassNav`       | `gm-nav`       | `orientation`, `spy`, `onNavigate`                              |
|               | `GlassSearch`    | `gm-search`    | `source`, `placeholder`, `label`, `hotkey`, `empty`, `onSelect` |
|               | `GlassScrollbar` | `gm-scrollbar` | `scroller`                                                      |
| `/overlays`   | `GlassPopover`   | `gm-popover`   | `anchor`, `placement`                                           |
|               | `GlassMenu`      | `gm-menu`      | `anchor`, `placement`, `onSelect`                               |
|               | `GlassDialog`    | `gm-dialog`    | `heading`, `placement`, `onClose`                               |
|               | `GlassTip`       | `gm-tip`       | `heading`, `anchor`, `placement`, `remember`, `onDismiss`       |
|               | `toast()`        | `gm-toast`     | a function, no component                                        |
| `/forms`      | `GlassSlider`    | `gm-slider`    | redraws after every render                                      |
|               | `GlassSelect`    | `gm-select`    | redraws after every render                                      |
|               | `GlassOtp`       | `gm-otp`       | `onComplete`                                                    |
|               | `GlassQuantity`  | `gm-quantity`  | redraws after every render                                      |
| `/data`       | `GlassTable`     | `gm-table`     | `density`, `stack`, `pin`, `onSort`, `onSelectionChange`        |

Chips, toggles, fields and checkboxes are classes, so they need no wrapper:
`<button className="gm-chip">`, `<input className="gm-input">`.

## Types

`GlassOptions` and `GlassTier` are re-exported from the core; `GlassAttributes`, `SearchResult`,
`SearchSource`, `NavigateDetail`, `CalloutType`, `MenuSelectDetail`, `SelectChangeDetail` and the
other event details from `@glass-midas/react/components`, and each from its own entry.
