
All exports are safe to import during server rendering; anything that needs the DOM checks for it first.

## createGlass

```ts
function createGlass(el: HTMLElement, options?: GlassOptions): GlassHandle;
```

Turns `el` into a glass surface at the best [tier](/concepts/tiers/) the browser supports, and sets
`data-glass-tier` on it.

### GlassOptions

| Option      | Type        | Default                   | Description                                                                           |
| ----------- | ----------- | ------------------------- | ------------------------------------------------------------------------------------- |
| Option      | Type        | Default                   | Description                                                                           |
| ----------- | ----------- | ------------------------- | ------------------------------------------------------------------                    |
| `radius`    | `number`    | `18`                      | Corner radius in px. Match the element's `border-radius`.                             |
| `bezel`     | `number`    | `20`                      | Width of the curved rim in px. `refract` only.                                        |
| `thickness` | `number`    | `24`                      | Height of the glass in px; thicker bends more. `refract` only.                        |
| `ior`       | `number`    | `1.5`                     | Index of refraction (water `1.33`, glass `1.5`). `refract` only.                      |
| `specular`  | `number`    | `0.6`                     | Rim highlight strength, 0 to 1. `refract` only.                                       |
| `curvature` | `number`    | `4`                       | Rim profile exponent: `2` circle, `4` squircle. `refract` only.                       |
| `magnify`   | `number`    | `0.1`                     | Magnifies the whole surface, `0` to `0.5`. `refract` only.                            |
| `caustics`  | `boolean`   | `false`                   | Let the rim fold the image into a mirrored band, as thick glass does. `refract` only. |
| `blur`      | `string`    | `var(--gm-blur-md, 16px)` | Any CSS length. Ignored at `solid`.                                                   |
| `tier`      | `GlassTier` | detected                  | Forces a tier instead of calling `detectTier()`.                                      |

See [Refraction](/concepts/refraction/) for the optics behind these options.

### GlassHandle

| Member            | Description                                                                           |
| ----------------- | ------------------------------------------------------------------------------------- |
| `tier`            | The tier in use. Fixed for the surface's lifetime.                                    |
| `update(options)` | Merges new options and re-renders. `tier` can't change; create a new surface instead. |
| `destroy()`       | Removes the effect, its SVG filter, its resize observer and `data-glass-tier`.        |

## detectTier

```ts
function detectTier(env?: SupportEnv | null): GlassTier;
type GlassTier = 'refract' | 'blur' | 'solid';
```

Returns the best tier for the current browser. The decision order is on the
[Tiers](/concepts/tiers/#how-the-tier-is-chosen) page.

Without an argument it inspects the real browser. Pass `null` to describe an environment with no
browser (always `solid`), or a `SupportEnv` to test the logic:

```ts
interface SupportEnv {
  supports(property: string, value: string): boolean; // like CSS.supports
  matchMedia(query: string): { matches: boolean };
  isChromium: boolean;
}

detectTier({ supports: () => true, matchMedia: () => ({ matches: false }), isChromium: false });
// 'blur'
```

## tokens

```ts
const tokens: Tokens;
```

The default design tokens, grouped by kind. Listed in the [token reference](/reference/tokens/).

## tokensToCss

```ts
function tokensToCss(selector?: string, source?: Tokens): string;
```

Serializes tokens as one CSS rule of custom properties. `selector` defaults to `:root`, `source` to
`tokens`.

## tokenVar

```ts
function tokenVar(group: TokenGroup, name: string): string;
```

Returns `var(--gm-<group>-<name>)`. Both arguments are type-checked against `tokens`.

## displacementMap

```ts
function displacementMap(
  width: number,
  height: number,
  optics: LensOptics,
  density?: number,
): LensMap | undefined;

interface LensOptics {
  radius: number;
  bezel: number;
  thickness: number;
  ior: number;
  specular: number;
  curvature?: number; // default 4
  magnify?: number; // default 0
  caustics?: boolean; // default false
}

interface LensMap {
  data: Uint8ClampedArray; // RGBA, row by row
  width: number; // in map pixels
  height: number;
  density: number; // map pixels per CSS px
  scale: number; // feDisplacementMap scale that restores CSS px
}
```

The map behind the `refract` tier, exported for building custom effects (for example as a WebGL
texture). It's a pure function with no DOM access, so it also runs on a server or in a worker.

Red encodes horizontal displacement and green vertical, with `128` meaning none; the strongest
shift uses the full range, and `scale` converts back to px. Blue holds the rim highlight. The model
is described on the [Refraction](/concepts/refraction/#the-model) page. Returns `undefined` for a
zero-sized area.
