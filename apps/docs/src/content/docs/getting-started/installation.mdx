## Packages

| Package                   | Use it for                                                                        |
| ------------------------- | --------------------------------------------------------------------------------- |
| `@glass-midas/core`       | Tokens, tier detection and the glass engine. Works with any framework.            |
| `@glass-midas/components` | Ready-made glass Web Components: navigation, search, tabs, callouts, code blocks. |
| `@glass-midas/react`      | The `useGlass` hook, `<Glass>`, and the components for React.                     |
| `@glass-midas/webgl`      | A WebGL renderer with floating-point optics and dispersion, in every browser.     |

## With a package manager

<Tabs syncKey="pkg">
  <Tab label="pnpm">

```sh
pnpm add @glass-midas/core
# components, React bindings or WebGL as you need them
pnpm add @glass-midas/components @glass-midas/react @glass-midas/webgl
```

  </Tab>
  <Tab label="npm">

```sh
npm install @glass-midas/core
# components, React bindings or WebGL as you need them
npm install @glass-midas/components @glass-midas/react @glass-midas/webgl
```

  </Tab>
  <Tab label="yarn">

```sh
yarn add @glass-midas/core
# components, React bindings or WebGL as you need them
yarn add @glass-midas/components @glass-midas/react @glass-midas/webgl
```

  </Tab>
</Tabs>

Every other package depends on the core, so installing one of them brings it along. The React
bindings expect React 18 or newer.

## From a CDN

The core and the components have no other dependencies, so they run without a bundler:

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@glass-midas/components/dist/styles.css"
/>
<script type="module">
  import 'https://cdn.jsdelivr.net/npm/@glass-midas/components/+esm';
</script>
```

Pin a version in production, for example `@glass-midas/core@0.1.0`.
