Two steps: load the tokens once, then attach glass to an element.

<Tabs syncKey="framework">
  <Tab label="JavaScript">
    ```html
    <div class="panel">Hello, glass</div>

    <script type="module">
      import { createGlass, tokensToCss } from '@glass-midas/core';

      // 1. Expose the design tokens as CSS custom properties.
      document.head.insertAdjacentHTML('beforeend', `<style>${tokensToCss()}</style>`);

      // 2. Attach glass. Match `radius` to the element's border-radius.
      const glass = createGlass(document.querySelector('.panel'), { radius: 28 });

      console.log(glass.tier); // 'refract' | 'blur' | 'solid'
    </script>

    <style>
      .panel {
        border-radius: var(--gm-radius-lg);
        background: var(--gm-tint-light);
        box-shadow: inset 0 1px 0 var(--gm-highlight-edge);
        padding: 2rem;
      }
    </style>
    ```

    Call `glass.destroy()` when the element goes away.

  </Tab>
  <Tab label="React">
    ```tsx
    import { tokensToCss, tokenVar } from '@glass-midas/core';
    import { Glass } from '@glass-midas/react';

    // 1. Once, at startup.
    document.head.insertAdjacentHTML('beforeend', `<style>${tokensToCss()}</style>`);

    // 2. Anywhere in the tree.
    export function Panel() {
      return (
        <Glass
          glass={{ radius: 28 }}
          style={{
            borderRadius: tokenVar('radius', 'lg'),
            background: tokenVar('tint', 'light'),
            padding: '2rem',
          }}
        >
          Hello, glass
        </Glass>
      );
    }
    ```

    `<Glass>` renders a `div`, accepts every `div` prop and cleans up on unmount.
    To make your own element glass, use [`useGlass`](/reference/react/#useglass).

  </Tab>
</Tabs>

## Glass needs something behind it

Glass bends and blurs what's _behind_ the element. Over a flat, single-color page there's nothing
to see. Put it over an image, a gradient or content that scrolls underneath.
