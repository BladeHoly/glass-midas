A [callout](/components/callout/) is glass, so it can't go inside a dialog or a surface. A note is
the same message without the glass: a tint of its status color and a hairline of the same, so it
reads on any fill. The words carry the meaning; the color only confirms it.

## Usage

<CodePanel>

```html
<p class="gm-note" data-tone="warning">The access key is as good as your password.</p>

<div class="gm-note" data-tone="danger" data-lines>
  <strong class="gm-note-heading">The server asked to slow down</strong>
  …a message with its own line breaks…
</div>
```

</CodePanel>

It's in `css/note.css`.

## Best practices

- **Callout or note?** On the page, a callout. Inside glass (a dialog, a surface) or in a panel next to
  glass, a note.
- **Say what to do**, not just what happened: "Saved as far as it got; try again in a few minutes."
