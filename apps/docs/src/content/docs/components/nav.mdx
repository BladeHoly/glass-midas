`<gm-nav>` holds links. A droplet of glass slides under the current one on a spring, stretching
as it moves, and follows the pointer and keyboard focus. The sidebar and the "On this page" list
of this site are both `gm-nav`.

## Usage

<CodePanel>

```html
<gm-nav orientation="vertical" spy>
  <a href="#intro">Intro</a>
  <a href="#install">Install</a>
</gm-nav>
```

```ts
nav.addEventListener('gm-navigate', (e) => {
  e.preventDefault();
  lenis.scrollTo(e.detail.target);
});
```

</CodePanel>

- **Page links:** mark the current page with `aria-current="page"`.
- **In-page links:** add `spy`, and the current link follows the scroll. A click keeps the clicked
  link current until the scroll arrives, so the droplet never steps back through the sections in
  between. Without `spy`, the clicked link simply becomes current.

## Anatomy

- **The host** is the glass bar, with `role="navigation"` unless you give it another role.
- **`.gm-droplet`** is the moving glass marker, under the link text.
- **Links** are any `a[href]` inside, at any depth, so you can group them under headings.

## Best practices

- **Keep labels short.** The droplet stretches to the link's width.
- **Don't put a lens over the text.** The droplet is thin, clear glass on purpose; magnifying
  glass over a label makes it unreadable.
