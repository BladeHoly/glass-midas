and a label for a control that doesn't sit in a [field](/components/field/).

## Usage

<CodePanel>

```html
<p>
  Open <button type="button" class="gm-link">your account page</button>, press
  <kbd class="gm-kbd">F12</kbd> and copy <code class="gm-code-inline">access_key</code>.
</p>

<span class="gm-label" id="q-label">Quality <span>(highest by default)</span></span>
<gm-segmented aria-labelledby="q-label">…</gm-segmented>
```

</CodePanel>

They're in `css/inline.css`.

## Best practices

- **A link goes somewhere, a button does something.** Use `gm-link` for an action that reads best
  inside a sentence; for navigation, a real `<a>`.
- **Point the control at its label** with `aria-labelledby` when it isn't a `<label for>`.
