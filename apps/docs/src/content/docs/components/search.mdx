`<gm-search>` is a glass search box with a crisp, lit rim, and a glass list of results under it.
The search at the top of this page is one, over a Pagefind index.

## Usage

<CodePanel>

```ts
interface SearchResult {
  label: string;
  href: string;
  hint?: string; // secondary text: a section, an excerpt
}

search.source = async (query) => {
  const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
  return res.json();
};
```

```ts
search.addEventListener('gm-select', (e) => {
  e.preventDefault();
  router.push(e.detail.href);
});
```

</CodePanel>

Give it a `source`: any function from the query to results, synchronous or not.

Answers that arrive after a newer query are dropped, so a slow request never overwrites a fast
one. Typing is debounced.

## Anatomy

- **`.gm-search-field`** is the glass box, with the icon, the input and the hotkey hint.
- **`.gm-search-results`** is the list, a separate glass surface, with `role="listbox"`.
- The input is a `combobox`: the arrows move through results, Enter picks, Escape closes.

## Best practices

- **Return a handful of results.** Eight is plenty; the list scrolls past that, but people don't.
- **Use `hint`** for what tells two similar results apart: the section, the type, an excerpt.
