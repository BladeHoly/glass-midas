`<gm-code>` wraps a `<pre>` and adds a copy button: an icon that turns into a check once copied. Every code block on this site is one.

/>

## Usage

<CodePanel>

```html
<gm-code>
  <pre><code>…</code></pre>
</gm-code>
```

</CodePanel>

Highlight the code however you like; `gm-code` only adds the glass and the button. Where the page
can't reach the clipboard, the button selects the code so it can be copied by hand.

## Best practices

- **Translate the button's name** with `label-copy` and `label-copied`; screen readers read it.
- **Keep the background of highlighted code transparent**, so the glass shows through.
