`<gm-segmented>` is a small switch between a few options: a mode, a view, a range. A droplet of
glass slides under the chosen one. Unlike [tabs](/components/tabs/), it shows nothing itself; it
holds a value and tells you when it changes.

## Usage

```html
<gm-segmented label="Mode" value="chat">
  <button value="chat">Chat</button>
  <button value="voice">Voice</button>
</gm-segmented>
```

```ts
const mode = document.querySelector('gm-segmented');
mode.addEventListener('gm-change', (e) => console.log(e.detail.value)); // 'voice'
mode.value = 'chat'; // moves the choice, no event
```

Options can hold an icon next to their text. An option with only an icon needs an `aria-label`.

## Anatomy

- **The host** is the glass bar, with `role="radiogroup"`.
- **Each option** (any child with a `value`) gets `role="radio"` and the class `.gm-segment`.
- **`.gm-droplet`** is the glass under the chosen option.

The arrow keys, Home and End move the choice, and only the chosen option is in the tab order.

## Best practices

- **Two to four options.** More than that is a menu.
- **Short labels, all the same kind:** modes, views or ranges, not a mix.
- **Use [tabs](/components/tabs/)** when the choice switches between panels of content.
