`<gm-table>` wraps a native `<table>`, so it reads as a table to screen readers and copies as
one. It adds sorting, filtering by column, row selection and a phone layout. It isn't glass: a table is content, so it
sits on a plain fill inside the page, with hairlines between rows and the numbers lined up.

## Usage

<CodePanel>

```html
<gm-table stack>
  <table>
    <thead>
      <tr>
        <th><input type="checkbox" class="gm-check" data-select-all aria-label="Select all" /></th>
        <th data-sort="name">Name</th>
        <th data-sort="total" class="gm-num">Total</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>
          <input type="checkbox" class="gm-check" data-select value="42" aria-label="Select Ada" />
        </td>
        <td>Ada</td>
        <td class="gm-num" data-value="1450">$1,450.00</td>
      </tr>
    </tbody>
  </table>
</gm-table>
```

```js
const table = document.querySelector('gm-table');
table.addEventListener('gm-selection', (e) => {
  bulkBar.hidden = !e.detail.values.length;
  count.textContent = `${e.detail.values.length} selected`;
});
```

```tsx
<GlassTable
  stack
  onSort={({ key, direction }) => setSort({ key, direction })}
  onSelectionChange={({ values }) => setSelected(values)}
>
  <table>…</table>
</GlassTable>
```

</CodePanel>

Load `css/table.css` and, for the checkboxes, `css/check.css`. Add `class="gm-num"` to number
columns to line them up on the right.

### Filters

A header with `data-filter` gets a small funnel. It opens the column's values, each with how many
rows have it; check one or several, and the rest of the rows hide. The button shows how many are
chosen, and **Clear** takes the filter off.

When the rows live on a server, list the values in `data-filter-options`, cancel `gm-filter` and
fetch with `detail.filters`. A row of status chips can stay in step by calling `filter()`:

<CodePanel>

```html
<th data-filter="status" data-filter-options="paid:Paid,pending:Pending,refunded:Refunded">
  Status
</th>
```

```js
table.addEventListener('gm-filter', (e) => {
  e.preventDefault(); // the server filters, so the counts and pages are right
  load({ status: e.detail.filters.status ?? [] });
});
// A chip that adds its status: the column's filter shows it too.
paidChip.addEventListener('click', () => table.filter('status', [...chosen, 'paid']));
```

```tsx
<GlassTable onFilter={({ filters }) => setStatus(filters.status ?? [])}>
  <table>…</table>
</GlassTable>
```

</CodePanel>

### In React

`GlassTable` from `@glass-midas/react/data`. Rows are React's, so with `onSort` or `onFilter` the
table leaves them alone: sort and filter your data in the handler.

## Best practices

- **Sorting, filtering, selection and the actions on a selection are one system.** Show how many
  rows an action affects. Ask before destructive actions, or offer undo.
- **Pick the density for the task:** compact for scanning many rows, relaxed for reading each one.
- **Say what's filtering:** "Paid or pending, online: 12 orders", with a way to clear it all.
- **Say when there's nothing:** an empty table needs a sentence and a way out, like "No orders
  match. Clear the filters."
- **Label every row checkbox** with what it selects: "Select order 1042".
