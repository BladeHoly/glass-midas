A log is what an app has been doing: one line per event, newest at the bottom, in a monospace font so
times and counts line up. Each line can carry a tone and a time.

## Usage

<CodePanel>

```html
<ol class="gm-log" aria-live="polite">
  <li data-tone="success"><time>12:04:06</time>Track 1 saved</li>
</ol>
```

```js
// Keep the newest line in view, unless the reader has scrolled up to read.
function add(log, li) {
  const atEnd = log.scrollTop + log.clientHeight >= log.scrollHeight - 4;
  log.append(li);
  while (log.childElementCount > 400) log.firstElementChild.remove();
  if (atEnd) log.scrollTop = log.scrollHeight;
}
```

</CodePanel>

It's in `css/log.css`.

## Best practices

- **Follow the newest line only while the reader is at the bottom**: jumping away from what they're
  reading is worse than not following.
- **Keep a cap** on the lines kept, so a long run doesn't grow the page forever.
