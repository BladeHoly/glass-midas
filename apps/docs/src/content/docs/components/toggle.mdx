A toggle switches one setting on or off. It's the native checkbox with a class, so forms,
keyboard and screen readers work as they always do, and there's nothing to load. Like a
[chip](/components/chip/), it sits inside glass rather than being glass: a light track, the
accent when it's on, and a white knob that stretches while it's held.

## Usage

<CodePanel>

```html
<label>
  Wi-Fi
  <input type="checkbox" class="gm-toggle" role="switch" checked />
</label>
```

</CodePanel>

### A setting row

For a list of settings, a row holds the name, a line about it and the switch at the end. The whole
row is the `<label>`, so it toggles anywhere it's pressed.

## Theming

| Property               | Use                               |
| ---------------------- | --------------------------------- |
| `--gm-toggle-on`       | The track when it's on.           |
| `--gm-knob`            | The knob, here and on the slider. |
| `--gm-chip-fill-hover` | The track when it's off.          |

## Best practices

- **Always label it**, with a `<label>` or `aria-label`.
- **It acts at once.** A setting that waits for a Save button is a checkbox, not a switch.
