`<gm-callout>` sets an aside apart from the text around it, on still glass with an accent on its
leading edge.

## Usage

```html
<gm-callout type="caution" heading="Early development">
  <p>The API will change.</p>
</gm-callout>
```

It gets `role="note"` unless you set another role.

## Types

| Type      | Use it for                                    |
| --------- | --------------------------------------------- |
| `note`    | Context worth knowing.                        |
| `tip`     | A better way to do something.                 |
| `caution` | Something that may not work as expected.      |
| `danger`  | Something that loses data or breaks the page. |

## Best practices

- **One callout per idea**, and rarely more than one per screen; several in a row read as noise.
- **Lead with the point** in the heading.
