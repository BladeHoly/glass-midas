`<gm-popover>` floats a panel of frosted glass next to the button that opens it. It's built on
the browser's popover API, so it lives in the top layer, above everything, and a plain
`popovertarget` on a button opens it: no script needed. Escape and a click outside close it.

## Usage

```html
<button popovertarget="share">Share</button>

<gm-popover id="share">…</gm-popover>
```

It sits below its button, centered on it and kept inside the window, and goes above when there's
no room below. To open it from code, call `open()`; to float it next to an element that isn't its
button, give it `anchor="that-id"`.

## Anatomy

- **The host** is the glass, with the `popover` attribute. The browser hides it while closed.
- Whatever you put inside: text, chips, a form.

## Best practices

- **One popover at a time.** Opening another closes the first, as `auto` popovers do.
- **For a list of actions, use a [menu](/components/menu/)**: it adds the roles and arrow keys.
- **Put controls inside as [chips](/components/chip/)**, not glass: glass inside glass can't see
  the page.
