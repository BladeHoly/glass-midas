A chip is a control inside glass. It isn't glass itself: glass inside glass can't see the page,
only its parent. So it's a light fill over the surface, brighter on hover, and the one that's on
(pressed, selected or current) gets the rim. It's a class, with no script.

## Usage

```html
<gm-surface material="frost">
  <button class="gm-chip gm-chip-plain" aria-pressed="true">Chat</button>
  <button class="gm-chip gm-chip-plain" aria-pressed="false">Voice</button>
  <button class="gm-chip gm-chip-round gm-chip-plain" aria-label="History"><svg>…</svg></button>
</gm-surface>
```

Set `aria-pressed` on toggles, `aria-selected` in a listbox or tabs, `aria-current` on links.
The styles follow the state, so the markup stays honest.

For a segmented control where the selection should slide, use [tabs](/components/tabs/): their
droplet is the moving version of the same idea.

## Theming

| Property               | Use                         |
| ---------------------- | --------------------------- |
| `--gm-chip-fill`       | Resting fill.               |
| `--gm-chip-fill-hover` | Under the pointer.          |
| `--gm-chip-fill-on`    | Pressed, selected, current. |

## Best practices

- **The rim marks the one that's on.** Don't add it to resting chips, or nothing stands out.
- **Floating over content on its own?** Then it's a [button](/components/button/), on glass.
