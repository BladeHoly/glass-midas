Three ways to choose one thing from a few, all on native radios. The browser keeps the keyboard
(arrow keys within a group), forms and screen readers; the classes only draw them.

- A **swatch** is a dot of a color, for finishes.
- A **choice** is a chip with a word, for sizes or editions.
- An **option** is a row with a title, a note and a price, for delivery speeds, payment methods
  and saved addresses.

The one that's on gets the rim, like every other piece that's on.

## Usage

<CodePanel>

```html
<fieldset class="gm-swatches">
  <legend>Finish: <strong>Obsidian</strong></legend>
  <input
    type="radio"
    class="gm-swatch"
    name="finish"
    value="obsidian"
    style="--gm-swatch: #1c1b22"
    aria-label="Obsidian"
    checked
  />
  <input
    type="radio"
    class="gm-swatch"
    name="finish"
    value="verdigris"
    style="--gm-swatch: #5fae9c"
    aria-label="Verdigris, sold out"
    data-unavailable
  />
</fieldset>

<fieldset class="gm-choices">
  <legend>Length</legend>
  <label class="gm-choice"><input type="radio" name="length" value="1" checked />1 m</label>
  <label class="gm-choice"><input type="radio" name="length" value="2" />2 m</label>
</fieldset>

<fieldset class="gm-options">
  <legend>Delivery</legend>
  <label class="gm-option">
    <input type="radio" class="gm-check" name="method" value="standard" checked />
    <span>Standard<small>3–5 working days</small></span>
    <span>Free</span>
  </label>
</fieldset>
```

</CodePanel>

All three are in `css/choice.css`; the option's radio is a [checkbox or radio](/components/check/),
from `css/check.css`. A swatch can show a picture of the material instead of a color:
`style="--gm-swatch: url(walnut.webp)"`.

## Best practices

- **Name every swatch** with `aria-label`: a color alone isn't a name. Put the chosen name in the
  legend too, so everyone sees it.
- **Say sold out in the name** ("Verdigris, sold out") as well as with `data-unavailable`.
- **Let the picture and price follow** the swatch: listen for `change` on the group.
- **Use options, not a select,** for two to five choices that differ in price or time; people
  compare them at a glance.

## Theming

| Property                | Use                               |
| ----------------------- | --------------------------------- |
| `--gm-swatch`           | A swatch's color or picture.      |
| `--gm-swatch-size`      | A swatch's size.                  |
| `--gm-chip-fill`, `-on` | The fill of choices and options.  |
| `--gm-rim`              | The rim on the one that's chosen. |
