Stars, two ways. **To show** a rating, a span filled to a value: 4.6 fills four stars and most of
the fifth. **To give** one, five radios: the checked star and those before it fill, and hovering
previews. The size follows the font in both.

## Usage

<CodePanel>

```html
<span class="gm-rating" style="--gm-rating: 4.6" role="img" aria-label="4.6 out of 5"></span>

<fieldset class="gm-rating-input">
  <legend>Your rating</legend>
  <input type="radio" name="stars" value="1" aria-label="1 star" required />
  <input type="radio" name="stars" value="2" aria-label="2 stars" />
  <input type="radio" name="stars" value="3" aria-label="3 stars" />
  <input type="radio" name="stars" value="4" aria-label="4 stars" />
  <input type="radio" name="stars" value="5" aria-label="5 stars" />
</fieldset>
```

```tsx
<span
  className="gm-rating"
  style={{ '--gm-rating': average } as React.CSSProperties}
  role="img"
  aria-label={`${average} out of 5`}
/>
```

</CodePanel>

Both are in `css/rating.css`. In forced colors mode the stars draw in the text color.

## Best practices

- **Show the count beside the stars.** 4.9 from 3 reviews means less than 4.6 from 300.
- **Make `required` the first radio** when a review needs stars, so the form says so before it's
  sent.

## Theming

| Property            | Use                              |
| ------------------- | -------------------------------- |
| `--gm-rating-fill`  | The filled stars (the ink).      |
| `--gm-rating-empty` | The empty ones.                  |
| `--gm-rating-size`  | The input's star size (1.75rem). |
