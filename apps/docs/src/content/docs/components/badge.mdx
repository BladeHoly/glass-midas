A badge is a status in one word, with a dot and a tint of its color. Color only where it means
something: done, waiting, wrong. An avatar is a person, as a picture or their initials.

## Usage

<CodePanel>

```html
<span class="gm-badge" data-tone="success">Paid</span>

<span class="gm-avatar" aria-hidden="true">AM</span> Ada Moreau
<span class="gm-avatar"><img src="ada.jpg" alt="Ada Moreau" /></span>
```

</CodePanel>

Both are in `css/badge.css`, along with skeletons and pagination.

## Theming

| Property           | Use                                                |
| ------------------ | -------------------------------------------------- |
| `--gm-status-*`    | The tones: `info`, `success`, `warning`, `danger`. |
| `--gm-badge-tone`  | One badge's color, for a tone of your own.         |
| `--gm-avatar-size` | An avatar's size.                                  |
| `--gm-avatar-fill` | The fill behind initials.                          |

## Best practices

- **The word first.** A badge must read without its color, for people who don't see it.
- **Few tones.** If everything is colored, nothing stands out.
- **Initials next to a name are decoration:** hide them from screen readers with
  `aria-hidden="true"`. A picture standing alone needs its `alt`.
