**Steps** show where a process is: an order from placed to delivered, a return from requested to
refunded, a wizard. Done steps fill with the ink and the current one is ringed. **A timeline** is
what happened, each event with its time: an order's history, with the notes the team left.

## Usage

<CodePanel>

```html
<ol class="gm-steps" aria-label="Order progress">
  <li data-state="done">Ordered<small>Oct 18</small></li>
  <li aria-current="step">On its way<small>Arrives Oct 22</small></li>
  <li>Delivered</li>
</ol>

<ol class="gm-timeline">
  <li data-tone="success">
    <time datetime="2026-10-18T16:02">Oct 18, 16:02</time>
    <p>Paid $449.00 by card</p>
  </li>
</ol>
```

</CodePanel>

Both are in `css/steps.css`.

## Best practices

- **Name the list** (`aria-label="Order progress"`): `aria-current="step"` then reads as "current
  step".
- **Give the next step a date** when you know it ("Arrives Oct 22"): it's the question people
  came with.
- **Keep the tones for events that mean something:** a payment, a refund, a problem. Most events
  stay gray.

## Theming

| Property          | Use                                         |
| ----------------- | ------------------------------------------- |
| `--gm-steps-fill` | Done steps and the line between them (ink). |
| `--gm-steps-dot`  | The dot's size.                             |
| `--gm-status-*`   | The timeline's tones.                       |
