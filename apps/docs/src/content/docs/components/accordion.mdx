An accordion is a stack of `<details>`: the browser brings the keyboard, find-in-page (a search
opens the section that holds the match) and, with a shared `name`, one-at-a-time. The class draws
hairlines between them and a chevron that turns, and where the browser can animate to an auto
height, the content slides open.

## Usage

<CodePanel>

```html
<div class="gm-accordion">
  <details name="faq" open>
    <summary>Specifications</summary>
    <p>50 mm beryllium drivers, 40 hours a charge, 310 g.</p>
  </details>
  <details name="faq">
    <summary>Shipping and returns</summary>
    <p>Free over $150. Send it back within 60 days.</p>
  </details>
</div>
```

</CodePanel>

It's in `css/accordion.css`. The slide needs `interpolate-size` and `::details-content`; elsewhere
the section opens at once, and with reduced motion it always does.

## Best practices

- **Leave the first section open** when it holds what most people came for.
- **Don't hide the price or the main button** in one: an accordion is for detail.
