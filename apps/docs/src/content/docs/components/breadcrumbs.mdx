Breadcrumbs say where a page sits: the store, the collection, the piece. One line, in the muted
ink, with a chevron between the steps; the page itself is the last one, and on a narrow screen it
shortens rather than wrap.

## Usage

<CodePanel>

```html
<nav class="gm-breadcrumbs" aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Ondine</a></li>
    <li><a href="/listen">Listen</a></li>
    <li><span aria-current="page">Tide</span></li>
  </ol>
</nav>
```

</CodePanel>

It's in `css/breadcrumbs.css`. The separators are drawn by CSS, so screen readers don't read them.

## Best practices

- **Link every step but the last.** The page you're on isn't a link.
- **Show the path, not the history.** Breadcrumbs follow the site's structure, whatever way
  someone came in.
