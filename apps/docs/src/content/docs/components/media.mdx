[Gallery](/components/gallery/) shows one picture at a time, for a product. A media grid shows many:
a downloader's results, a folder, an album. Tiles keep their shape, labels sit in their corners on a
frosted pill so they read over any picture, and a ring marks the ones that need a look.

## Usage

<CodePanel>

```html
<div class="gm-media-grid" style="--gm-media-min: 150px" aria-label="Downloaded photos">
  <button class="gm-media-tile" data-ratio="3/4" aria-label="Open photo 1, 2400 by 3200">
    <img src="…" alt="" />
    <span data-corner="top-end">#2</span>
    <span class="gm-badge" data-corner="bottom-start">2400×3200</span>
  </button>
</div>
```

</CodePanel>

It's in `css/media.css`. How many tiles to keep (the last 60, say) is up to the page.

## Best practices

- **Name each tile** with `aria-label`: the picture's own `alt` can stay empty when the label says it.
- **Keep the ring for what needs a look**, a lower size or an error, not for decoration.
