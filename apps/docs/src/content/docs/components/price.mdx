A **price** says what something costs now. On sale, it also says what it cost before and how much
that saves, all on one baseline, with the numbers in tabular figures so they line up. **Totals**
are the lines of a bill: subtotal, discount, shipping, tax and what's paid, in a `<dl>`.

## Usage

<CodePanel>

```html
<p class="gm-price">
  <data value="349">$349.00</data>
  <s><span class="visually-hidden">was </span>$449.00</s>
  <span class="gm-price-off">−22%</span>
</p>

<dl class="gm-totals">
  <dt>Subtotal</dt>
  <dd>$678.00</dd>
  <dt>Shipping</dt>
  <dd>Free</dd>
  <dt class="gm-totals-total">Total</dt>
  <dd class="gm-totals-total">$678.00</dd>
</dl>
```

</CodePanel>

Both are in `css/price.css`.

## Best practices

- **Say "was" for screen readers.** Most of them read `<s>` as plain text, so "$349 $449" would
  sound like two prices. A hidden "was " fixes it.
- **Show every cost before checkout:** shipping, tax and discounts in the totals, so the last step
  holds no surprise.
- **Write money with `Intl.NumberFormat`,** in the shopper's currency, and keep the number in
  `<data value>` for scripts.
