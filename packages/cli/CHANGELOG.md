# @glass-midas/cli

## 0.1.0

Initial release: `glass-midas`, the docs from the terminal for people and coding agents.

- `list` the components, every page or a section; `docs <name>` prints any page as Markdown; `find <words>` searches names, descriptions and text; `setup [html|react|astro]` shows how to install and load glass-midas in the project, offline.
- `--json` on `list` and `find`; `GLASS_MIDAS_DOCS` points it at another copy of the docs.
