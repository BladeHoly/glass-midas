# @glass-midas/cli

The [glass-midas](https://bladeholy.github.io/glass-midas/) docs and templates from the terminal, for you or your coding agent.

```sh
npx @glass-midas/cli list            # the components
npx @glass-midas/cli docs gm-search  # any page as Markdown
npx @glass-midas/cli find frost      # pages that cover it
npx @glass-midas/cli setup react     # install and load it in this project
npx @glass-midas/cli template cart   # copy a whole screen into ./cart
```

Docs: <https://bladeholy.github.io/glass-midas/reference/cli/> · MIT
